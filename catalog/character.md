# 角色素材總覽

> 最後更新：2026-07-07

## 目錄結構（先分風格）

角色在「素材類型」之下多一層 **風格母分類**：

```
assets/{授權分類}/character/{風格}/{套件名}/SOURCE_LICENSE.md
```

範例：`assets/1-free-commercial/character/pixel-art/chromoxi-good-and-evil/`

## 風格母分類

| 風格 slug | 說明 |
|-----------|------|
| `pixel-art` | 像素風 |
| `toon-cartoon` | 卡通／Q版 |
| `vector-flat` | 向量／扁平 |
| `anime-2d` | 動漫／立繪 |
| `low-poly-3d` | 3D 低多邊形 |

| 分類 | 清單 | 收錄 |
|------|------|------|
| 完全免費授權商用 | [01-free-commercial.md](01-free-commercial.md) | 15 套（待手動下載） |
| 商用需購買授權 | [02-paid-commercial.md](02-paid-commercial.md) | 清單 3 套 |
| 不確定相關規範 | [03-license-unclear.md](03-license-unclear.md) | 1 套待確認 |

機器可讀：[character.json](character.json)
