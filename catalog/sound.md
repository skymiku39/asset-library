# 音效素材總覽

> 最後更新：2026-07-07

## 目錄結構（先分風格）

音效在「素材類型」之下多一層 **風格母分類**，先依風格分類再放套件：

```
assets/{授權分類}/sound/{風格}/{套件名}/SOURCE_LICENSE.md
```

範例：`assets/1-free-commercial/sound/realistic-foley/kenney-casino-audio/`

機器可讀：[sound.json](sound.json)

## 風格母分類

| 風格 slug | 說明 | 適用場景 |
|-----------|------|----------|
| `realistic-foley` | 寫實擬音（牌／籌碼／骰子） | 撲克、麻將、賭場類的實錄操作音 |
| `ui-modern` | 現代 UI 介面音 | 按鈕、確認、切換、提示 |
| `retro-8bit` | 復古 8-bit／街機 | 像素風、街機、休閒小遊戲 |
| `casino-bgm` | 賭場／爵士氛圍 BGM | 牌桌、賭場、休閒背景音樂 |
