# UI 素材總覽

> 最後更新：2026-07-07

## 目錄結構（先分風格）

UI 在「素材類型」之下多一層 **風格母分類**，先依風格分類再放套件：

```
assets/{授權分類}/ui/{風格}/{套件名}/SOURCE_LICENSE.md
```

範例：`assets/1-free-commercial/ui/flat-clean/kenney-ui-pack/`

機器可讀：[ui.json](ui.json)

## 風格母分類

| 風格 slug | 說明 | 適用場景 |
|-----------|------|----------|
| `flat-clean` | 扁平／簡潔 | 現代休閒、通用選單、按鈕面板 |
| `pixel-ui` | 像素 UI | 像素風、街機、復古小遊戲 |
| `casual-cartoon` | 休閒卡通 | 消除、賭場、休閒手遊 |
| `fantasy-rpg` | 奇幻 RPG | 冒險、卡牌、對話框與視窗邊框 |
| `sci-fi` | 科幻 | 太空、科技、極簡玻璃感介面 |
